The dipole was initially configured with both elements angled approximately 45°. With the antenna indoors, the elements were repositioned into a roughly vertical orientation while receiver frequency, bandwidth, and gain were held constant.
The vertical configuration produced a noticeable increase in received signal strength.

Note: The antenna was kept in the angled configuration above while being moved to multiple locations. Window, inner bedroom and kitchen produced sufficient variance in environment to produce useful results. 

Window Observations:
  - Observed signals were strong and clear. Required no changes to gain.

Bedroom Observations:
  - Multiple configuration changes were made to the antenna during this phase due to lack of signal presence.
  - Ultimately some signals were received but were significantly degraded compared to other location tests.

Kitchen Observations:
  - Multiple antenna configurations were tested and signal quality was sufficient.

Vertical Dipole Observations: 
  - This configuration provided the best signal quality for the Kitchen environment described above.
  - Some testing had to be done using multiple gain levels to find highest quality.
    
Conclusion: Antenna orientation affects received signal strength because of polarization alignment and the local propagation environment. Indoor reflections and nearby objects can also influence the measured result through multipath.
